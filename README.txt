메디링고 설치형 웹앱 (PWA)

이 폴더의 파일을 웹에 올리면 갤럭시에서 '앱 설치'로 설치할 수 있어요.
설치하면 홈 화면 아이콘으로 열리고, 한 번 연 뒤에는 인터넷이 없어도 돌아가요.

[GitHub Pages에 올리기 — 무료]
1. github.com 가입 후 로그인
2. 오른쪽 위 + → New repository → 이름: medilingo → Public → Create repository
3. "uploading an existing file" 클릭 → 이 폴더 안의 파일 전부 업로드
   (index.html, sw.js, manifest.webmanifest, 아이콘 png 4개)
   → Commit changes
4. Settings → Pages → Branch: main, 폴더 / (root) → Save
5. 1~2분 뒤 https://아이디.github.io/medilingo/ 주소가 생겨요

[갤럭시에 설치]
1. 크롬으로 위 주소 열기
2. 오른쪽 위 ⋮ → '앱 설치' (또는 '홈 화면에 추가') → 설치
3. 홈 화면의 '메디링고' 아이콘으로 실행

[새 장이 추가되면]
새 index.html만 같은 저장소에 다시 올리면 돼요(덮어쓰기).
앱을 한 번 껐다 켜면 새 버전으로 바뀌어요.

※ 학습 기록은 그 휴대폰 안에만 저장돼요. 앱을 지우거나 사이트 데이터를 지우면 기록도 사라져요.
